# Validation

Validate contracts, repository tests, Postman collections, MongoDB behavior,
logging, tracing, metrics, security, accessibility, integration, deployment,
rollback, and traceability. Before approval, also run the generic change
package validator and the separate design screenshot-to-acceptance review
when a design source is declared. Record evidence per task and never report
implementation readiness while a source, scope, visual, or acceptance
comparison blocker remains.
